# 01 · 项目总览与功能规格

> 基于 2026-10-22 代码状态编写（win64 / win32 均为 V0.0.4）。
> 本文是功能与界面的规格来源：第 4 节是逆向自原版 SSCOM 5.13.1 的行为基线，
> 第 5 节起是 PyCom 的当前实现规格。改任何功能前先查对应章节，行为以本文为准。

## 1. 项目是什么

**PyCom** 是用 Python 从头复刻 SSCOM 5.13.1 串口/网络调试器的项目：串口 +
TCP 客户端/服务端 + UDP 全模式收发、多条发送、校验追加、发送文件、终端仿真、
转换计算器、原版 `sscom51.ini` 导入，并在此之上增强（多编码显示、大缓冲、
搜索高亮、断线自动重连、深色模式）。无广告、无联网行为。MIT 许可
（关于对话框内可见）。

不依赖原版 exe，串口走 QtSerialPort（**不用 pyserial**），打包用 PyInstaller。

## 2. 两个产物分支

| 项 | `win64/`（主线） | `win32/`（Win7 回迁分支） |
|---|---|---|
| 应用名 | **PyCom** | **PyCom32** |
| 版本 | V0.0.5（`app/version.py` 单一来源） | V0.0.5（同左） |
| 技术栈 | Python 3.13（64 位）+ PySide6 / Qt6 | Python 3.8.10（**32 位**）+ PySide2 5.15.2.1 / Qt5 |
| 串口 | QtSerialPort | QtSerialPort（同 API） |
| 目标系统 | Windows 10+ | Windows 7 SP1+（32/64 位均可，产物是 32 位 exe） |
| 产物 | `dist\PyCom.exe`（单文件，≈24MB） | `dist\PyCom32.exe`（单文件，≈20MB） |
| 显示缓冲 | 默认 10M / 上限 100M | 默认 5M / 上限 50M（500K~上限可调，2026-10-20 放宽） |
| 单测 | 127 项全过 | 136 项全过（多出的为 Qt5 专属守卫） |
| 维护模式 | 功能收口在这里 | 仅手工同步主线修复，**不开新功能** |

两分支代码同源：`win32/` 是 `win64/` 的整树副本 + 一层明确的 Qt5/32 位适配
（适配清单见 [04-Win7-32位适配说明.md](04-Win7-32位适配说明.md)）。主线改完代码先跑
根目录 `sync_check.py` 判断要不要移植。

### 4.3 原版功能清单

**连接**
- 串口：端口、波特率（可自定义，含 1000000~3000000 高波特率档）、数据位 5/6/7/8、
  停止位 1/1.5/2、校验 无/偶/奇/Mark/Space、流控；DTR/RTS 信号线开关；串口列表刷新；
  启动时立即打开；串口设置菜单含帮助。
- 网络：TCP 客户端（远程 IP:port）、TCP 服务端（本地 port）、UDP（本地+远程）；
  网卡选择下拉（可刷新枚举）联动本地 IP 列表，三个网络模式共用。
- 串口接收缓冲满 80% 时自动把显示缓冲扩到 200K。

**接收显示**：ASCII/HEX 切换（HEX 每行 16 字节）；加时间戳和分包显示（空闲超时
默认 20ms 可调，包首带时间戳）；清除窗口；保存数据；接收数据直接保存到文件。

**发送**：多行发送编辑框，ASC/HEX 切换，大“发送”按钮；加回车换行（0D 0A）；
定时发送（间隔可调）；校验追加；发送文件 256 字节分块、五档延时；终端仿真。

**多条字符串发送**：最多 99 条；每条含注释、ASC/HEX、独立延时；行点击发送；
循环发送；+/- 增删；导入 ini。

**小工具**：数据波形（示波器）、STM32/GD32 ISP 烧写器、STC/IAP15 ISP 烧写器、
转换计算器、LUA 脚本（标注未支持）。

**其它**：中/English 界面切换、窗口置顶、窗口几何与全部参数自动保存。

## 5. PyCom 功能规格（当前实现）

菜单栏：**通讯端口 │ 串口设置 │ 编码 │ 显示 │ 发送 │ 多条字符串 │ 小工具 │ 帮助**
（“编码”菜单为 PyCom 新增，位于串口设置与显示之间；小工具菜单 =
进制转换 / ASCII码表 / 多条字符串发送（扩展页直达）│ 计算器 /
设备管理器 / 文件资源管理器；帮助菜单 = **检查更新…** /
关于——检查更新即用默认浏览器打开仓库 Releases 页
（`github.com/smartmx/PyCom/releases/latest`），最新版发布与下载在网页进行，
应用内不联网、不做自动下载）。

### 5.1 连接

- 串口：端口（下拉不可编辑，热插拔后可刷新）、波特率（预置档 + 自定义，
  含 1000000~3000000）、数据位 5/6/7/8、停止位 1/1.5/2、校验 无/偶/奇/Mark/Space、
  流控；DTR/RTS 开关；“启动立刻打开串口”为菜单选项（默认关，`open_on_start` 持久化）。
  **修改波特率后自动重开串口**（CH34x 类芯片动态 setBaudRate 不可靠，统一走重开）。
- 网络：TCP 客户端（远程 IP:port）、TCP 服务端（本地 port，**多客户端**收发）、
  UDP（本地+远程）；网卡下拉联动本地 IP（悬停显示全名，可刷新枚举），
  三个网络模式共用。
- **IPv4/IPv6 纯单栈**：本地 IP 下拉列出 0.0.0.0（仅 IPv4 全部）+ 各 IPv4 +
  ::（仅 IPv6 全部）+ 各 IPv6（链路本地 fe80::x%作用域 直接可用），**选中哪个
  地址就只绑定/收发该族，两族互不混收**（服务端/UDP 绑 :: 时 IPv4 客户端连不上，
  反之亦然）；**TCP 客户端仅选了"具体网卡地址"才预绑定**（2026-10-20 引入、
  2026-10-22 二十轮 F1 收口）：具体地址=限定源地址/出口网卡；"全部"档
  （0.0.0.0/::）、回环与未配置一律不绑——源与协议族交回 Qt 由目标地址决定，
  主机名保留 v4/v6 多地址回退（出厂默认 local_ip=0.0.0.0；若预绑定回环会把
  源钉死，连局域网设备报 Network unreachable）；绑定失败（如选了本机不存在的
  地址）立即报"本机IP绑定失败"。远程地址支持
  IPv4/IPv6 字面量，`[::1]` 方括号写法自动剥除（**主机名仅 TCP 客户端支持**
  ——`connectToHost` 走 DNS；UDP 只认地址字面量，`QHostAddress` 不做域名
  解析）；UDP 远程地址无法解析或发送失败时报一次状态栏提示（链路保持绑定，
  界面保持已连接、仅亮 ERR 灯）、恢复后自动回正常（定时发送不刷屏）。
  不做双栈。**与模式无关的输入框自动锁死**：TCP 客户端锁「本机端口」、
  TCP 服务器锁「远程 IP/端口」（置灰 + 悬停显示"TCP 客户端无需配置本机
  端口"/"TCP 服务器无需配置远程IP和端口"），UDP 四项全有效。
- 模式切换走菜单“通讯端口”（QActionGroup 互斥），网络模式自动换左下连接区；
  连接指示灯：灰=未连接、绿=已连接、黄=重连中、红=错误。

### 5.2 接收显示

- ASCII / HEX 切换（HEX 每行 16 字节）；自动滚屏可关（关闭后新数据只入缓冲不跟随）。
  **用户回看自动取消勾选**（2026-10-20 定稿）：滚轮上翻、拖拽形成选区、拖动滚动条
  （**松手时不在底部**，方向无关）都会自动取消"自动滚屏"勾选——视图停住，持续接收
  下可安心选择复制；再次勾选立即跳回最底部（无需等新数据）。该取消随 `pycom.json`
  持久化（下次启动保持关闭），再次勾选后恢复。
- 时间戳+分包：空闲超时切包（默认 20ms 可调）；未勾选时显示纯文本；勾选后每个
  **包首行**带 `[HH:MM:SS.mmm]收←◆/发→◇`（方向标识随分包开关，且只在包首行），
  续行只有数据。该开关只影响**显示与转存**——时间戳前缀与包边界一直随行记录，
  复制/保存是否带出由下面的两个右键选项独立决定（切换勾选后对已收数据同样生效）。
- 复制/保存含时间戳和收发标记：接收区右键菜单两项独立开关（默认勾选，勾选态 =
  行尾 `●`）："复制含时间戳和收发标记"/"保存含时间戳和收发标记"。关闭时
  「复制所选/复制全部文本」与「保存数据」只出正文；开启时行首 `[时间戳]收←◆`
  随行带出（选区从行首列 0 起选中的行才带注记，半途起选的行不带）。两开关随
  `pycom.json` 持久化（`copy_with_anno` / `save_with_anno`）。
- 编码：菜单“编码”12 种预置（GBK 默认/GB2312/GB18030/UTF-8/UTF-16LE·BE/Big5/
  Shift-JIS/EUC-JP/EUC-KR/cp1252/Latin-1）+“自定义编码…”对话框（任意 Python
  编码名，经 `codecs.lookup` 校验）。收/发/终端按键/日志全部走统一入口
  `MainWindow._current_encoding()`，切换实时生效、只影响后续数据。
- 显示缓冲上限：菜单 500K~100M（win64，默认 10M）/ 500K~50M（win32，默认 5M；2026-10-20 删 200K 档并放宽上限，老配置的更小值收敛到 500K）；
  行表跟随缓冲裁剪——接收区回看范围 ≈ 保存 `*.bin` 的导出范围；行表另有
  **50 万行硬上限**（设计见 [02-架构与代码导读.md](02-架构与代码导读.md) 第 7 节）。
- 窄窗缩放（对齐 SSCOM，阈值 **920px** 管查找条/状态栏的让位；扩展面板为
  独立小窗，与窄窗无关）：宽度缩窄时右侧内容**不隐藏**——工具行右区
  （打开文件/路径框/发送文件/停止/清发送区/收起/最前/保存参数/扩展）与
  右侧选项两列按设计宽固定排列、整体被窗口右缘直接裁剪；清除窗口/查找/
  新窗口/自动滚屏与左下角串口配置列**永不压缩/移位**；窗口最窄可到 330px，
  展宽即恢复。行内不放 stretch，行尾 stretch 独占全部增减——按钮间隙恒定。
- 固定布局（V0.0.5）：上述按钮类控件位置恒定；**显示框/发送内容框跟随
  窗口伸缩**（最小宽 160/120）。主窗内容画布宽 = max(视口宽, 内容最小宽)，
  收缩到固定控件所需最小宽以下时画布冻结、只裁右边，任何按钮不被挤压。
- 扩展面板独立小窗（V0.0.5）：点"扩展"（或小工具菜单直达）在主窗口右侧
  弹出独立小窗（宽约 335px——由扩展面板内容最小宽自适应；高度随主窗
  客户区，紧贴右缘、随主窗移动/缩放跟随贴边）；主窗右缘贴屏（如最大化）
  时自动改贴主窗左缘、再不行夹回屏幕内；主窗最小化时小窗随之隐藏、
  恢复时重新显示；小窗被 × 直接关闭会同步主窗按钮复位。显示框与主界面
  布局完全不受影响。
- 工具行文件块（打开文件/路径框/发送文件/停止/清发送区，V0.0.4 新增"新窗口"
  之后）：**起始横坐标恒定 = 左下角"发送"按钮的右缘再加一个英文字符宽**
  （垫片按渲染坐标实测，任何窗口宽度都对齐；缩窗时该块保持宽度、被窗口
  边缘截断不隐藏）。
- 字体/颜色：发送区、接收区**独立**字体设置（family/size/bold/underline/color），
  另有背景色/文字颜色/时间戳颜色。
- 清除窗口；保存（文本 `received.txt` / 原始字节 `received.bin`）；文本内容按
  "保存含时间戳和收发标记"选项带出注记（默认含）。
- 接收数据到文件（转存）：勾选即生效、无文件对话框；文件名
  `PyCom-Log-YYYYMMDD_HHMMSS.txt`（exe 同目录），内容=接收区显示文本
  （含时间戳前缀、随 ASCII/HEX 模式；**仍随"加时间戳和分包显示"勾选，不受
  复制/保存选项影响**），按勾选时编码保存；100ms 增量落盘只写
  新收尾行；每次勾选新建。**长期完整留档用它**，不受缓冲上限影响。

### 5.3 发送

- 多行发送编辑框，ASC/HEX 切换；定时发送（间隔可调）；加回车换行（0D 0A）。
- 发送文件：256 字节/块，延时档 连续/1/10/50/100ms（由“发送”菜单的
  QActionGroup 驱动），进度条+停止。
- 终端仿真（两发送方式互斥）：回车后发送新行(带回显)（默认选中，对齐 SSCOM；
  接收区点击即可输入，含输入法）/ 按键立即发送该键值（含方向键 ANSI 序列）；
  本地回显按键值仅与按键方式搭配；回车 0x0d 自动补 0x0a。

### 5.4 多条字符串发送

- 最多 **100** 条（原版 99）；每条：注释、ASC/HEX、独立延时、顺序号。
- SSCOM 语义：表格“发送”按钮列单击即发送、双击改注释；顺序号 0=跳过不参与；
  循环发送按“顺序号排序、逐条按各自延时”推进；循环自停时表格勾选态同步取消。

### 5.5 校验追加

- 算法 7 种（`app/core/checksum.py` `CHECKSUM_KINDS`）：无 / ModbusCRC16 /
  CCITT_CRC16 / CRC8 / ADD8 / ADD16 / XOR8，第 N 字节起算。
- 位置（对齐 SSCOM）：末尾 1~4 字节视为帧尾、校验插在帧尾**前面**；
  “末尾追加”为旧版保留档。
- ADD/XOR 按 8/16 位累加/异或实现（原版规格未公开，如有出入改
  `app/core/checksum.py`）；ModbusCRC16 低字节在前。

### 5.6 小工具与其它

- 进制转换（原“转换计算器”更名，V0.0.4）：DEC/HEX/BIN/ASCII/float 大小端
  （内嵌扩展区页签，也可从小工具菜单打开）；ASCII码表与多条字符串发送页签
  同样可从小工具菜单直达；设备管理器入口；导入sscom.ini配置（在多条发送
  页签，仅导入多条）。
- 扩展区（多条发送页签）默认隐藏，“扩展”按钮展开，可拖分栏；启动时强制收起
  （不持久化展开态）。
- 状态栏五段：连接状态 │ TX 速率 │ RX 速率 │ 连接信息/通知 │ 版本（QFrame 凹陷
  分格）。**第 1 框只显示 已连接/未连接**；其余一切提示（错误、重连中、发送
  积压、转存开启、编码/缓冲切换、参数保存结果等）走**第 4 框临时通知**：显示
  后 3 秒内有新通知则刷新，超时无新通知自动回显常驻的串口参数/TCP/UDP 连接
  信息；“重连中…”因每次重连尝试（默认 2s，小于 3s）都会刷新而持续可见。
  TX/RX 计数右键清零。
- 窗口置顶；全部参数持久化到 `pycom.json`（点“保存参数”或关窗时写入）。
- 界面语言：中文（原版的中英切换未实现）。

### 5.7 增强与新功能（原版没有的）

1. **无广告**、无联网行为（天然无）。
2. **多编码显示**：12 预置 + 任意手输，增量解码跨包不乱码。
3. **大缓冲显示**：默认 10M/上限 100M（win32 为 5M/50M），溢出自动丢最旧；
   win32 内存真耗尽时自动降档并在状态栏提示，不崩。
4. **接收区搜索+高亮着色**：Ctrl+F 呼出；文本/HEX 模式、大小写、命中计数与
   上下跳转；发送=蓝色、接收=绿色着色。
5. **断线自动重连**：串口拔出/网络断开按间隔自动恢复（可关，`reconnect_ms`
   默认 2000），状态栏提示“重连中…”。
6. **深色模式**：显示菜单切换，浅/深两套主题，着色随主题适配；Windows 标题栏、
   状态栏/面板立体边框等原生元素同步跟随。

## 7. 界面设计要点

- 布局按 4.2 分区图 1:1 对应：顶部 接收区约 46% 宽｜右侧多条发送（默认隐藏）；

  标题栏（DWM 沉浸式暗色，Win10 1809+ 生效）、状态栏分段框等原生元素经显式
  调色板同步跟随。
- Windows 任务栏图标：启动时先设 AppUserModelID（否则按 python.exe 分组）；
  打包图标来自 `assets/pycom.ico`（由 `tools/make_ico.py` 从 svg 生成）。
